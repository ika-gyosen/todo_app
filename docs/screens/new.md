# 新規作成画面（`/new`）

## 画面概要
- TODOの新規作成フォームを提供。

## 表示項目
- ヘッダー
  - 戻るボタン: `戻る`
  - タイトル: `新しいTODO`
  - 作成ボタン: `作成`
- 入力フォーム
  - タイトル入力（必須）
  - 詳細（Markdown）入力
  - プレビュー

## 操作
- 戻るボタン
  - 未保存の変更がある場合: 未保存確認ダイアログ
  - 変更がない場合: `/` に戻る
- 作成ボタン
  - タイトル未入力: 非活性
  - タイトル入力済み: `addTodo` 実行 → `/` に遷移

## バリデーション
- タイトルは必須（空/空白のみは不可）

## ダイアログ
- 未保存確認ダイアログ
  - タイトル: `未保存の変更`
  - メッセージ: `入力内容が破棄されます。戻りますか？`
  - 確認: 破棄して `/` に遷移
  - キャンセル: 閉じる

## 画面遷移
- `/new` → `/` : 作成 / 戻る
