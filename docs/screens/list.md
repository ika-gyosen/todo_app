# 一覧画面（`/`）

## 画面概要
- カンバン形式でTODOを3カラム（Todo / InProgress / Done）に分けて表示。
- 未完了件数を表示（Todo + InProgress）。
- ドラッグ&ドロップでステータス変更が可能。

## 表示項目
- 画面タイトル: `TODO Board`
- 未完了件数: `{未完了件数} 件の未完了タスク`
- 追加ボタン: `追加`
- カンバンカラム（3列）
  - Todo: 未着手のタスク
  - InProgress: 進行中のタスク
  - Done: 完了したタスク
- カンバンカード
  - タイトル（1行、長い場合は省略）
  - 詳細の先頭40文字（存在時のみ、省略あり）
  - 完了時は透明度を下げて表示

## 操作
- 追加ボタン: `/new` に遷移
- カードクリック: `/edit/:id` に遷移
- カードドラッグ&ドロップ: 別カラムにドロップでステータス変更

## レイアウト
- モバイル（md未満）: 1カラム表示（縦に並ぶ）
- タブレット以上（md以上）: 3カラム表示

## ドラッグ&ドロップ
- **ライブラリ**: dnd-kit（@dnd-kit/core, @dnd-kit/sortable, @dnd-kit/utilities）
- **センサー**: PointerSensor（distance: 8px）、KeyboardSensor
- **ドラッグ開始**: カードをドラッグするとopacity低下、スケールアップ、影が追加される
- **ドロップ可能表示**: カラムにホバーすると背景色・ボーダー色が変化、リングハイライト表示
- **ドラッグオーバーレイ**: ドラッグ中のカードプレビューをDragOverlayで表示

## 状態
- カラムにTODOが0件: `タスクがありません` を表示

## 画面遷移
- `/` → `/new` : 追加
- `/` → `/edit/:id` : カード選択
