# 一覧画面（`/`）

## 画面概要
- TODOの一覧と「追加」導線を提供。
- 未完了件数を表示。

## 表示項目
- 画面タイトル: `TODO List`
- 未完了件数: `{未完了件数} 件の未完了タスク`
- 追加ボタン: `追加`
- TODOカード（一覧）
  - チェックボックス（完了状態）
  - タイトル（1行、長い場合は省略）
  - 詳細の先頭60文字（存在時のみ、省略あり）
  - 右向き矢印アイコン

## 操作
- 追加ボタン: `/new` に遷移
- TODOカードクリック: `/edit/:id` に遷移
- チェックボックス: 完了状態のトグル

## 状態
- TODOが0件: 空状態メッセージを表示
  - 文言: `TODOがありません`
  - 補助文: `「追加」ボタンから新しいタスクを作成`

## 画面遷移
- `/` → `/new` : 追加
- `/` → `/edit/:id` : カード選択
