# 編集画面（`/edit/:id`）

## 画面概要
- 既存TODOの編集、ステータス変更、削除を行う。

## 表示項目
- ヘッダー
  - 戻るボタン: `戻る`
  - タイトル: `TODOを編集`
  - ステータスセレクトボックス: `Todo` / `InProgress` / `Done`
  - 削除ボタン: `削除`
  - 保存ボタン: `保存` / `保存済み`
- 入力フォーム
  - タイトル入力（必須）
  - 詳細（Markdown）入力
  - プレビュー
- メタ情報
  - 作成日時: `作成: <ja-JP表示>`

## 操作
- 戻るボタン
  - 変更がある場合: 未保存確認ダイアログ
  - 変更がない場合: `/` に戻る
- ステータスセレクトボックス
  - 選択肢: `Todo`, `InProgress`, `Done`
  - 変更はローカル状態で保持、保存ボタンで永続化
- 保存ボタン
  - 変更なし: `保存済み` 表示（非活性）
  - 変更あり: `保存` 実行（タイトル、詳細、ステータスを保存、画面遷移なし）
- 削除ボタン: 削除確認ダイアログを表示

## 変更検知
- タイトル、詳細、ステータスのいずれかが変更されると`hasChanges`がtrueになる
- 保存ボタンが活性化される

## バリデーション
- タイトルは必須（空/空白のみは不可）

## 例外状態
- 指定IDのTODOが存在しない場合
  - メッセージ: `TODOが見つかりません`
  - 一覧に戻るボタンで `/` に遷移

## ダイアログ
- 削除確認ダイアログ
  - タイトル: `削除の確認`
  - メッセージ: `このTODOを削除しますか？この操作は取り消せません。`
  - 確認: `削除` → `/` に遷移
  - キャンセル: 閉じる
- 未保存確認ダイアログ
  - タイトル: `未保存の変更`
  - メッセージ: `未保存の変更があります。保存せずに戻りますか？`
  - 確認: 破棄して `/` に遷移
  - キャンセル: 閉じる

## 画面遷移
- `/edit/:id` → `/` : 戻る / 削除
